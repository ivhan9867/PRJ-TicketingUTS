Array, Struct, Pointer

Tiga konsep dasar yang menopang seluruh data di halaman ini.

Struct

Satu tiket adalah satu struct: sembilan field dalam satu satuan, total 128 byte. Panjang tiap blok sebanding dengan ukurannya di memori.

Array

Semua struct disimpan berurutan: Tiket tiket[N]. Satu struct = 128 byte, jadi alamat elemen berikutnya naik 0x80.

Pointer

Pointer menyimpan alamat elemen, bukan salinannya. *ptr membaca isi di alamat itu.

Linked List

Pesananmu disimpan sebagai rantai node. Setiap node menyimpan next, yaitu pointer ke node berikutnya.
